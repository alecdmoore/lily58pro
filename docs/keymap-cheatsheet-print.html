Home-row mods · OFF by default
A / ; → ⇧ 240ms S / L → ⌃ D / K → ⌥ F / J → ⌘ toggle: H on the Fn layer
An opt-in overlay — ⌃ ⌥ ⌘ are already on the thumbs. While on: tap the letter, hold for the modifier. Mirrored on both hands, both emitting left-side mod codes, as kanata does on the laptop. A hold only becomes a modifier when chorded with the other hand or a thumb — same-hand rolls just type. Thumbs and the two inner Spotlight keys are neutral, so ⌘⌫ / ⌘␣ / ⌘⏎ work from either side. Mods stack (hold F + D, tap J = ⌘⌥J). Pressed inside a typing burst (~125ms, 100ms for shifts) a mod is forced to its letter; tap-then-hold within 200ms auto-repeats the letter. For same-hand ctrl chords — ^A ^C ^D ^E ^R ^W ^Z are all left-hand — use the ⌃ thumb key.
Thumbs: ⌃ ⌥ ⌫/⌘ ␣/Nav, mirrored. Inner two are mod-taps — tap types Enter / Backspace, hold gives ⌥ / ⌘. On Nav the same thumbs keep the modifier and change the tap to Esc / Tab / Del.
Bottom-outer keys are the only Shift on layer 0, so they are mod-taps: hold = Shift, tap = ⌃B (herdr) left, ⌃⌘⌥ (Wispr hands-free) right. On Nav they tap Caps Lock.
Inner keys: Spotlight ⌘␣ on base, Maccy ⌘⇧C on Nav, ⌘⌃⇧3 screen-to-clipboard on Fn.
Nav: ⌥← / ⌥→ word-wise. Left hand = AeroSpace ⌥4/⌥3/⌥2/⌥1 and ⌥7/⌥8/⌥9/⌥0 in their old Raise-layer spots; the brackets they displaced moved up a row. Home / PgUp / PgDn / End run down the outer column on both halves. Brightness fills the bottom-right pair.
Fn: F1–F15 left, numpad right, Bluetooth down the left column (BT0–BT4, BT✕ = clear). ⌘⇧4 / ⌘⇧3 capture to file, replacing v14's Snip Tool / Print Screen.
Shift: number row → ! @ # $ % ^ & * ( ) +; punctuation → _ " < > ?; letters uppercase.
Still missing: the AeroSpace ⌥-workspace shortcuts — nothing in v14 replaces them.
