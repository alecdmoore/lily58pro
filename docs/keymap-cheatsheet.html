Lily58 Pro — Layer Map

Adapted from the jwoolson v14 layout for the Lily58 Pro / Beekeeb Allium58 GLP, with the Windows-only keys swapped for macOS equivalents. Modifiers live on the thumbs; two hold-layers reached from the pinkies and thumbs; home row mods available as an opt-in overlay.
NAV hold Space or Enter FN hold Tab or − HRM toggled, off by default changed from the v14 sheet dashed = pass-through two labels on a cap = tap over hold
🛠️
Not built yet — push to build, then flash both halves. This is a full replacement for the old Lower / Raise / Super scheme. Green dots mark where it departs from the v14 sheet: Spotlight (⌘␣) on the inner keys instead of Alfred, Maccy (⌃⇧C) instead of the macOS clipboard viewer, and ⌘⌃⇧4 instead of the Win11 clipboard. Snip Tool / Print Screen became their macOS counterparts, and the Bluetooth keys are carried over from the old keymap — the v14 sheet has none, and without them there is no way to switch or re-pair hosts. kanata also needs a daemon restart: it grabs every keyboard on the Mac, so kanata.kbd carries macos-dev-names-exclude ("Lily58").
Base — keycaps
Home-row mods — opt-in overlay

Off by default. Toggle it with the H key on the Fn layer (hold Tab, tap H) and it stays on until you toggle it back. While on, each home-row key becomes a hold-tap: a quick press still types the letter, holding it produces a modifier. Everything else on the board is unaffected. The mods are mirrored across both hands and only engage when chorded with a key on the other hand — so ⌘ is hold-F + tap C, while a same-hand roll like fd just types the letters. Both hands emit left-side mod codes, exactly as kanata does; only shift is sided.

You may not need it ⌃ ⌥ ⌘ are already on the thumbs, always available and with no timing rules at all. The overlay is for when you would rather not move off the home row.
Cross-hand only A hold only becomes a modifier if the key it is chorded with sits on the opposite hand, or on a thumb. Same-hand presses resolve to the letter, so fast rolls type normally.
Thumbs count as either hand All eight thumb keys — plus the two inner Spotlight keys — are neutral, so ⌘⌫, ⌘␣ and ⌘⏎ work from either side.
Mods stack Hold F and D, then tap J for ⌘⌥J. The positional check is deferred to release, so a second mod can pile onto the first.
Same-hand escape hatch ^A ^C ^D ^E ^R ^W ^Z are all left-hand letters, so hold-S can never reach them. Use the ⌃ thumb key instead — thumbs are exempt from the cross-hand rule.
Typing-burst guard Pressed within ~125 ms of the previous key (100 ms for the shifts), a mod is forced to its letter. Stops rolls from firing modifiers; pause a beat before a chord.
Shift — held modifier
Hold-layers

Thumbs read ⌃ ⏎/⌥ ⌫/⌘ ␣/Nav │ ␣/Nav ⌫/⌘ ⏎/⌥ ⌃, mirrored. The two inner mod-taps type Enter and Backspace on a tap and hold Option and Command; the ⌃ keys are plain Control. On the Nav layer the same three thumbs keep their modifier and change only the tap — Esc, Tab, Del. Bottom-outer keys are the only Shift on layer 0, so they are mod-taps rather than plain shortcuts: hold = Shift, tap = ⌃B on the left (herdr prefix) and ⌃⌘⌥ on the right (Wispr Flow hands-free). On Nav they become Caps Lock on tap, Shift on hold. Inner keys are Spotlight (⌘␣) on layer 0, Maccy (⌃⇧C) on Nav, and region-to-clipboard (⌘⌃⇧4) on Fn. Nav: ⌘← / ⌘→ are line start and end — the v14 sheet has ⌥← / ⌥→ for word-wise movement here. Vertical nav sits in the outer column, Home / PgUp / PgDn / End top to bottom, on both halves. Brightness fills the last two free slots in the bottom-right, extending the media block down a row — Bri+ sits on the Enter/Nav key, so reach it by holding a Space thumb rather than the pinky. Fn: F1–F15 on the left, numpad on the right, Bluetooth down the left column (BT0–BT4, BT✕ = clear). ⌘⇧4 and ⌘⇧3 are region and full-screen capture to file, where the v14 sheet has Snip Tool and Print Screen. Shift: the standard US layout — number row → ! @ # $ % ^ & * ( ) +, punctuation → _ " < > ?, letters uppercase. Still missing from the old keymap: the AeroSpace ⌥-workspace shortcuts. Nothing in the v14 layout replaces them — there is room on the Fn layer's left hand if you want them back.
